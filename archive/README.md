# Archived material

This directory contains non-notebook historical helper code. Historical notebooks are centralized under [`notebooks/archive/`](../notebooks/archive/).

Generated run outputs, notebook checkpoints, Python bytecode, test caches, and the MkDocs `site/` directory are reproducible local artifacts; they are not archived or versioned. Reusable application modules live in `target_selection/`. The historical MOP–DP2 helper remains under `analyses/mop_dp2/archive/`.
