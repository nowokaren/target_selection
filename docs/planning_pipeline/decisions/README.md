# Planning decisions

Record decisions that should persist between observing seasons here. One file per topic or decision is preferable to an unstructured running log.

Suggested fields:

- Date and decision owner
- Question being decided
- Decision and status (`provisional`, `adopted`, or `superseded`)
- Evidence or instrument measurements used
- Consequences for selection, ranking, or scheduling
- Date or condition for review

The priority flow is a design proposal until its magnitude, S/N, cadence, and diagnostic-visit thresholds have been checked against HSH/JS data.
