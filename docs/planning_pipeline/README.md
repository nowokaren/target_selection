# Planning pipeline workspace

This folder is the working home for planning-pipeline documentation, decision records, and design notes.

- [`priority_flow/`](priority_flow/README.md) contains the first-pass scientific and operational target-classification flow.
- [`decisions/`](decisions/README.md) is the place to record choices that affect future planning runs.

Keep proposed rules distinguishable from calibrated thresholds. Each decision record should include its date, the choice, the evidence or instrument measurements behind it, and whether it is provisional or adopted.
