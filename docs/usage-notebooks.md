# Version 2 usage notebooks

The notebooks in `notebooks/v2/` are the examples for the modular API under development. The older notebooks in `notebooks/` document historical analyses and are intentionally not compatibility targets.

| Notebook | Purpose |
|---|---|
| `01_catalog_loading_and_selection.ipynb` | Configure sources, load catalogs, and apply filters |
| `02_seasonal_visibility_selection.ipynb` | Select targets for a new HSH/JS observing season |
| `03_lsst_matching_and_products.ipynb` | Match visits/coadds and create analysis products |
| `04_photometry_and_lightcurves.ipynb` | Cache photometry and build light-curve products |
| `05_developer_add_an_adapter.ipynb` | Add a new API adapter, such as OGLE |
| `06_microlensing_followup_prioritization.ipynb` | Prioritize HSH/JS microlensing follow-up for an El Leoncito season |
