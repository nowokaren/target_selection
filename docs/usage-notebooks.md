# Notebooks

The active general notebooks are collected in the repository's `notebooks/` directory, with an inventory in `notebooks/README.md`. They are independent examples and scientific workflows; their names do not imply an execution order.

For a complete seasonal plan, use `notebooks/workflows/seasonal_observing_plan.ipynb`. For small API calls, use `notebooks/tutorials/task_api_examples.ipynb`. Provider inspection, daily HSH selection, Rubin coverage, DIA match validation, and the JS/HSH meeting report each have dedicated notebooks listed in the collection README.

The MOP–DP2 study has its own notebooks under `notebooks/analysis/mop_dp2/` and is not a second version of the general collection.
