# Version 2 usage notebooks

These notebooks belong to the new modular API. The historical notebooks in the parent directory are retained as legacy analyses and are not part of this interface.

- `01_catalog_loading_and_selection.ipynb`: configured sources, filters, and optional data.
- `02_seasonal_visibility_selection.ipynb`: target selection for a new HSH/JS observing season.
- `03_lsst_matching_and_products.ipynb`: visits, coadds, property maps, cutouts, and reports.
- `04_photometry_and_lightcurves.ipynb`: photometry cache and light-curve products.
- `05_developer_add_an_adapter.ipynb`: extension point for OGLE or another API.
- `06_microlensing_followup_prioritization.ipynb`: prioritize microlensing follow-up for the next El Leoncito season.
